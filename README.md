# M3 Gimnasio — guía visual

Sitio estático de ejercicios organizado por grupo muscular. No necesita servidor propio ni proceso de compilación.

## Publicación

La página se publica desde la raíz del repositorio con GitHub Pages. El archivo de entrada es `index.html`; las fotos del logo y del gimnasio están dentro de `assets/`.

Las fotos de los ejercicios se solicitan desde Free Exercise DB y requieren conexión a internet en el teléfono del visitante. La guía incluye 42 ejercicios y crédito a esa biblioteca en el pie de página.
